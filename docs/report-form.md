## 欄位

| # | 題目 | 類型 | 必填 | 選項／說明 |
|---|---|---|---|---|
| 1 | 回報類型 | 單選 | ✓ | 查無此商品／資料有誤／配方或包裝已變更／商品已停售／其他建議 |
| 2 | 商品名稱 | 簡答 | ✓ | 說明：例如「乖乖 椰子口味」 |
| 3 | 品牌 | 簡答 | | |
| 4 | 條碼號碼 | 簡答 | | 說明：條碼下方的 13 位數字。回應驗證：規則運算式 `^\d{8}$|^\d{12,14}$`（可留空） |
| 5 | 在哪裡看到這項商品 | 核取方塊 | | 全聯／7-11／全家／其他 |
| 6 | 哪裡有誤？ | 核取方塊 | | 成分／營養標示／過敏原／標籤／通路／圖片／其他 |
| 7 | 詳細說明 | 段落 | | |
| 8 | 商品照片 | 檔案上傳 | | 只允許圖片，最多 5 個檔案，單檔 10 MB。說明：正面、成分表、營養標示、條碼 |
| 9 | 商品代碼（自動帶入，請勿修改） | 簡答 | | 網站自動填入 |

第 6 題可以直接放在同一頁（Google 表單的條件分支只能依「單選」跳頁；保持單頁比較簡單，使用者不相關就略過）。
