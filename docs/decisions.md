# 翻背面（flipside）— 專案決策紀錄

台灣超市加工食品的成分／營養標示查詢網站，手機優先。

## 範圍
- 加工食品：飲料、零食、餅乾糕點、冰品、加工肉品（收錄）、泡麵、乳製品。排除酒類。
- 優先通路：全聯、7-11、全家。
- 第一版品牌：聯華、喜年來、義美、統一、味全、黑松、光泉、乖乖、桂格、華元、泰山、愛之味、新東陽、台畜。
- 不做營養評分（不用 Nutri-Score / NOVA）。
- 致癌／風險標示：第一版**不做**。只考慮成分表上的物質（不含加工過程產生的物質）。資料結構先把成分標準化成物質代碼，之後再替物質加屬性。

## 資料
- 來源：品牌官網（文字或圖片 OCR）、Open Food Facts、通路線上商城。
- 條碼：先從 OFF／通路網站抓，使用者到賣場拍照補充。第一版以搜尋＋瀏覽為主，查無則導向回報表單。
- 通路：先比對通路線上商城，標記「待確認」，由使用者在本機審核頁人工確認。
- 不同口味算不同商品；不同容量算同一商品（多條碼）。
- 欄位包含：成分、營養標示（另換算每 100g/ml）、過敏原、基改原料、原產地。
- 正向標籤只採認證：有機、雨林友善、動物福利、非基因改良、CAS、產銷履歷（2026-11-05 加入後兩者）。包裝上的「天然」「健康」不採計。
- 主要資料來源：萬家福線上購物（2026-11-05 決定）。約 1,800 個目標品牌商品頁，其中不少頁面只有行銷文字、沒有成分。
- 圖片：第一版直接引用萬家福的圖片網址（不下載進 repo），記錄來源網址，設置權利人下架管道。

## 功能
- 搜尋（中文模糊）、分類瀏覽、篩選（分類、產地、排除特定成分、過敏原、標籤、素食）、收藏（localStorage）。
- 通路不放篩選：瀏覽頁上方有「全部通路／全聯／7-11／全家」切換列，選擇會記住（情境是人已經在店裡）。只列已確認販售的商品。
- 搜尋支援俗稱：隱藏搜尋詞（同義詞、俗稱、子品牌）放在 data/aka.json，建置時寫進商品的 keywords，只用於搜尋、不顯示。品名直接命中的結果排在只命中俗稱的前面。
- 多尺寸：同一商品一頁，營養標示上方切換容量；表格依序為「整瓶／整包」（每100 × 容量換算，箱購以單瓶計）、包裝上的「每份」（與整包相同時省略）、「每100」。原始單位和容量單位不同時標「約」。掃條碼會自動選該容量。列表顯示最小容量的整包熱量。各尺寸若配方不同，拆成獨立商品。
- 回報：Google 表單。照片欄位保留、選填（有上傳欄位就需要登入 Google）。網站帶入預填參數。
- 審核頁：只在電腦本機使用，不部署；匯出 review.json 再合併。
- 流量統計：GoatCounter（另開站點）。
- 商品頁先不放品牌官網連結。

## 技術
- 純靜態網站 + JSON，部署在 GitHub Pages（公開 repo），PWA 可離線。
