# 人工審核與資料更新指南

這份是交接給人工作業用的。網站資料由腳本自動整理，但有些地方機器判斷不了，需要人看過。

## 一、開啟審核頁

1. 在 `flipside` 資料夾開終端機，執行：
   ```bash
   python -m http.server 8765
   ```
2. 瀏覽器開 http://localhost:8765/review/
3. 審核進度會自動存在這個瀏覽器裡；關掉再開也還在。換電腦前請先「匯出」。

## 二、各分頁要做什麼（建議順序）

| 分頁 | 內容 | 怎麼處理 |
|---|---|---|
| **需確認** | 從 Open Food Facts、喜年來官網補上的資料；或營養標示沒寫「每份／每100」的 | 點「開啟來源頁」對照，選「正確」或「不是同一商品」 |
| **數值與成分衝突** | 同一頁有兩組不同的成分或營養標示 | 選正確的那組；都不對就展開「我來改」貼上正確文字 |
| **分類** | 自動分類 | 錯的直接改；非加工食品勾「不收錄」 |
| **缺資料** | 有成分但缺營養標示（或反過來） | 對照包裝，把文字貼進去；暫時沒資料可勾「先隱藏」 |
| **標籤確認** | 自動偵測到的 CAS、有機、非基改等 | 只保留包裝上真的有認證標章／法定標示的 |
| **未對應添加物** | 成分括號裡、但成分資料庫沒有的字 | 選它屬於哪個成分；不是添加物就選「忽略」 |
| **通路** | 全聯／7-11／全家有沒有賣 | 點格子切換 ✓ ✗ ?；逛賣場時對照最準。「全✓」可整欄設定 |
| **條碼** | 商品條碼 | 輸入條碼按 Enter 跳下一格（有條碼才能用掃描功能找到） |
| **俗稱** | 隱藏搜尋詞（只用來搜尋，網站不顯示） | 填一般人會怎麼叫這個商品，例如「綠乖乖」；多個用逗號分隔。灰字是自動產生的 |
| **小包** | 有獨立小包裝的零食，一小包幾公克 | 看包裝填公克數（和外包裝尺寸無關，家庭號只是多幾包）；沒有小包留空。黃底是品名寫「N入」自動帶入的，對了按「確認」。列表會顯示「一小包 18g 92 大卡」 |
| **查無資料** | 萬家福和其他來源都沒有成分的商品，網站暫不顯示 | 參考用：逛賣場時拍包裝背面，交給 Claude 建檔 |

## 三、把審核結果放進網站

1. 審核頁右上角按「匯出 review.json」
2. 把下載的 `review.json` 移到 `flipside/review/` 資料夾
3. 執行：
   ```bash
   node scripts/04-merge-review.mjs
   node scripts/03-build.mjs
   ```
4. 開 http://localhost:8765/site/ 檢查
5. commit 並 push 到 GitHub，約 1–2 分鐘後 https://mengyahh.com/flipside/ 會更新

> 審核結果存在 `data/overrides.json`，之後重新抓資料也不會被蓋掉。

### 俗稱與同義詞（data/aka.json）

搜尋時，商品除了品名、品牌、分類，還會比對一組隱藏搜尋詞（products.json 裡的 `keywords`）。這些詞不會顯示在網站上，但 products.json 是公開檔案，所以別放不想公開的內容。來源有四種，都在 `data/aka.json`：

- **synonyms**（同義詞）：品名含同組任一詞，就加入其他詞。例如品名有「鮮乳」，搜「鮮奶」「牛奶」也找得到。
- **rules**（俗稱規則）：`match` 是正規表示式，比對「品牌 子品牌 品名」，可加 `brand` 限定品牌。例如「多多」→ 養樂多。
- **categories**：整個分類共用，例如泡麵分類加「速食麵」。
- **products**：單一商品，審核頁「俗稱」分頁填的會合併到這裡。

另外，萬家福標題前面的子品牌（例如「可樂果」「茶裏王」）會被切掉、不顯示在品名上，但會自動存成搜尋詞。改完 aka.json 後執行 `node scripts/03-build.mjs` 就會生效。

## 四、用包裝照片補資料

最省事的方式：把商品正面、成分表、營養標示、條碼的照片交給 Claude，請它「把這些商品建進翻背面」。它會把文字整理進 `data/overrides.json` 並重建。

## 五、重新抓取最新資料（例如每季一次）

```bash
node scripts/01-sitemap.mjs        # 萬家福網站地圖
node scripts/02-fetch.mjs          # 只抓還沒有快取的頁面；要全部重抓先刪除 .cache/pages
node scripts/05-off-download.mjs   # Open Food Facts 台灣商品
node scripts/06-brand-serena.mjs   # 喜年來官網
node scripts/03-build.mjs
```

## 六、資料來源與限制

- **萬家福線上購物**：主要來源。約一半商品頁只有行銷文字、沒有成分。
- **喜年來官網**：成分、營養、條碼、販售通路都有，品質最好。
- **Open Food Facts**：志工建立的資料庫，台灣商品約 3,500 筆，品質不一，所以補上的資料都會列在「需確認」。
- **未採用**：聯華官網（成分表的 API 被 robots.txt 禁止）、好市多與 PChome（成分多為圖片或需執行 JavaScript）、義美生機網站（品項少且沒有文字成分）。
- 通路資料目前只有喜年來官網提供的部分，其餘都要人工勾選。
- 網站上所有未人工核對的商品都會顯示「請以實際包裝標示為準」。
